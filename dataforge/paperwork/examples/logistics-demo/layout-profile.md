# 本教学算例版式参数落地

依据：journal-adaptation.md（其原有政策记录本次不冒充重新联网核查）。此文仍为中文合成教学工作稿，不是符合Transportation Science语言及投稿条件的成稿。

参数与实现：

- 单栏、≥11pt、1.5倍行距、1英寸边距：A4单栏、12pt正文、1.5倍、2.54cm，scripts/render.py Word样式及templates/latex/manuscript.tex。
- 题名：首个#单独作为居中22pt黑体题名，不计入章节；22pt为工作稿选择，不是期刊明确指定。匿名稿不添作者、单位或日期。
- 图：保留SVG源图；Word使用4倍PNG，居中置于版芯内；图下唯一图题与图同页。蓝/青配色、实虚线与标记，轴单位齐全。图1–3连续，文件名fig2–fig4保留以维持工件标识。
- 表：表题在上、三线表、无竖框，列宽在版芯内。
- 引文：作者年份工作稿转换，原文献仅元数据核验的事实保留；不声称语义审计完成。
- PDF：由本机Word通道实际导出，逐页预览；本机没有xelatex，LaTeX源稿没有实际编译验证。

最终实测尺寸、分辨率、产物哈希与逐页审阅见draft/render-review.json。只做版式修复与同参数重算，不改变原仿真模型；原算例的科学有效性不由排版验收背书。
