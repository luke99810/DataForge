# 期刊适配档案（Journal Adaptation）
- 目标期刊/文章类型：
- 作者指南 URL 与访问日期：
- 官方模板（Word/LaTeX/Overleaf）与模板 URL：
- 单栏或双栏、纸型与边距、行号要求：
- 结构要求（章节组织、标题层级上限、摘要结构/字数、关键词数量、Highlights/图文摘要）：
- 格式参数（正文字号行距、标题格式、图表题注、参考文献体例）：
- 图表规格（图幅/版芯、dpi、配色线型、公式排版）：
- 篇幅（字数/页数/图表数限制或建议、附录要求）：
- 投稿材料清单（投稿信、作者贡献、利益冲突、伦理、数据可用性、AI 使用声明等）：
- 特有要求（匿名审稿、数据/代码可得性声明、Reporting summary 等）：
- 政策核查日期；投稿前须重新核查最新政策：
