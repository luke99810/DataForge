# 数据发现与合法公开来源

先取得scope许可，再discover。优先本地原始数据、采集说明、代码及历史运行；只读相关文件，不整盘全文扫描。排除虚拟环境、缓存、版本库和含凭证/密码/隐私名字路径；名称过滤并非个人信息检测，仍须人工最小化范围。

缺数据时逐列列出变量、单位、粒度、覆盖年份、最小样本与许可要求，按官方统计/政府开放数据→机构仓储→论文补充材料顺序检索。用web_search、web_extract保存真实访问内容；必要时browser_exec读取合法DOM。记录失败、访问日期、URL、许可条款、原始工件SHA、转换代码与派生链。只有元数据时不能宣称数据已经下载；无许可则阻塞再分发，不擅自爬取登录/付费/个人敏感数据。

source命令登记已合法取得的本地工件，不自动判断许可。URL查询可能含密钥，CLI拒绝查询与凭证URL，若公开来源确需查询参数，另存经审阅不含密钥的来源说明和规范landing URL。合成数据用urn:synthetic:...并标记synthetic，绝不能替代实证缺口。

provenance补充转换规则、缺失值、去标识化、聚合与异常处理；隐私/伦理采集及共享范围重大选择暂停确认。数据/代码可得声明应如实说明本地、公开仓储或受控访问情况、版本和限制，不自动补写upon reasonable request或虚构DOI仓储。
