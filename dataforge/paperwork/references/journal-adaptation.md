# 期刊适配与写作框架生成（Journal Gate）

期刊门（`journal`）是 Idea2Paper 的第二道门，紧跟 `idea` 门：研究简报确认目标期刊后，核查该期刊当前作者指南，把 `references/generic-framework.md` 的初稿框架适配为**本项目**的写作框架 `framework.md`。此后 `assets`/`literature`/`model`/`compute`/`claims`/`writing` 各门都按该框架执行；换刊时重新执行本门并复核后续门产出。

## 输入与前置

- 目标期刊 + 文章类型 + 作者指南 URL，来自 `research_brief.md` 的"目标期刊/文章类型/政策URL和核查日期"字段（`idea` 门已确认，用户批准）。
- 未定期刊不进入本门：先回 `idea` 门确认，或用占位符登记"待定"并明确阻塞。

## 核查纪律（Agent 承担，脚本只登记）

- 只以**官方作者指南**为准：出版社/期刊官网的 Guide for authors、Submission guidelines、模板选择器页面；使用 `web_search`/`web_extract`，必要时 `browser_exec` 读取合法 DOM；**不得以二手教程、他人总结或模型内部知识代替官方指南**。
- 记录访问 URL、访问日期（政策会变）、AI/伦理/数据可得性声明要求；投稿前须重新核查最新政策。
- JCR/分区信息如需引用，核实年份与学科，不用 SJR 替代。
- 模板优先：期刊提供专用 Word/LaTeX 模板时，`framework.md` 中的格式参数由模板覆盖，本技能给出的通用数值仅作工作稿底稿。

## 提取参数（写入 `journal-adaptation.md`）

|类别|提取项|
|---|---|
|期刊与文章类型|目标期刊、文章类型（research/article/review 等）、作者指南 URL、政策核查日期|
|模板与版式|是否提供官方模板（Word/LaTeX/Overleaf）、单栏或双栏、纸型与边距、行号要求|
|结构要求|章节组织惯例（IMRaD 或变体）、标题层级上限、摘要结构/字数、关键词数量、是否要求 Highlights/图文摘要|
|格式参数|正文字号行距、标题层级格式、图表题注位置与字号、参考文献体例（作者年份制/顺序编码制、编号格式）|
|图表规格|图幅/版芯、分辨率 dpi、配色与线型要求、公式排版方式|
|篇幅|字数/页数/图表数限制或建议、附录与补充材料要求|
|投稿材料|投稿信、声明（作者贡献/利益冲突/伦理/数据可用性/AI 使用）、Cover letter 等清单|
|特有要求|匿名审稿、数据/代码可得性声明、Reporting summary 等期刊特有项|

## 生成 `framework.md`（自动修改初稿框架）

Agent 依据 `references/generic-framework.md` + `journal-adaptation.md` 生成项目级 `framework.md`：

1. **结构映射**：把通用框架的章节（题目摘要引言/问题建模/实验设计/结果讨论结论/配图/排版）映射到期刊结构；期刊要求合并且/或调整时（如综述、实证、理论、短文），删除或合并不适用章节并写明理由；不为凑结构硬塞章节。
2. **每章落位**：逐章写本项目的研究内容占位（该写什么、证据是什么），不写执行日志。
3. **图表规划**：按期刊图幅/dpi/配色要求规划图组与表格；每图绑定对应结果与 claim。
4. **篇幅分配**：按期刊字数/页数约束分配各章篇幅，标出可删减点。
5. **格式落地**：把期刊格式参数整理为可直接建立的样式清单（字体/字号/行距/标题层级/文献体例）。
6. **投稿材料清单**：列出该期刊要求的全部附加材料。

`framework.md` 的完成标准：结构与期刊要求一致、每章要点对应本研究、图表规划绑定证据、篇幅分配符合期刊约束、格式参数可直接落地。将 `journal-adaptation.md` 与 `framework.md` 的 SHA 登记为 `journal` 门证据。

## 边界与限制

- 期刊一旦提供专用模板，模板覆盖通用数值；已发表论文的版式只能参考结构，不照抄其排版细节。
- 不把"某期刊用 10 pt 双栏"推广为所有期刊要求；不以页数/字数硬凑篇幅。
- AI 辅助、伦理、作者与数据声明必须按目标期刊当前政策写，不得猜写；`publication_ready` 仍需人类批准。
- 换刊：重新执行本门 → 更新 `journal-adaptation.md`/`framework.md` → 复核受影响的 `claims`（图表规格）与 `writing`（结构与格式）产出，不能只改期刊名。
