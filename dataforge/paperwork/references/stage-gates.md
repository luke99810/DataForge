# 阶段门禁与科研责任

|门|最低证据|阻塞条件|
|---|---|---|
|idea|研究问题、对象、可检验目标、创新边界、关键选择批准|把方法名称当研究问题|
|journal|官方作者指南核查记录、期刊适配档案 journal-adaptation.md、本项目写作框架 framework.md、模板优先原则|无作者指南核查/未定期刊就撰写、把已发表版式当模板、猜写AI伦理声明|
|assets|限定范围清单、数据字典、来源许可、口径、缺失处理|数据缺失或权限不明却写实证|
|literature|检索式与日期、正反文献、真实元数据、阅读级别|把摘要/元数据当全文论断|
|model|变量单位、假设、约束/识别、基线、验证标准|重大假设未确认、不可识别|
|compute|测试、真实run、种子环境、诊断、最优性/误差证据|失败/超时/未求解/旧输出|
|claims|逐字段数值、口径、图表与运行一致|缺数据、超容差、越界外推|
|writing|全文风格映射、引用语义、正式论证、可得性声明|无全文却声称全文改写、虚构作者伦理|
|reflection|缺陷检查与修复、负结果、限制、人类最终判断|只做格式lint就称投稿就绪|

state只能在证据完成后声明pass。脚本核验完整阶段名单、审阅者字段和证据hash，但不验证审阅者资格或科研充分性。允许各学科某检查项不适用，必须写明理由；不可删除整个阶段来通过门禁。教学demo文献/全文范本不适用且publication_ready=false，不可将其gate移用于正式论文。

统计研究需视适用性报告样本单位、独立性/重复测量、排除规则、样本量依据、检验方向、效应与不确定性、多重比较、诊断；贝叶斯研究说明先验与链诊断。优化研究核验可行域、上下界/gap、最优性证据、基线/消融、敏感性和计算预算。理论研究需证明条件、反例和适用边界。仿真种子或参数盒不等于置信区间。

## 人工批准与证据门禁

`validate` 只做机械完整性，绝不把 Agent 自填的 stage `pass` 当科学审查。`publication_ready=true` 必须同时提供 `human_approval`：`status=approved`、`reviewer_role=human`、真实批准人和批准记录的 SHA；脚本不会创建或批准该字段。审阅者角色必须区分 `agent`、`human`、`independent_reviewer`，不能用“self-check”满足人类批准。

来源台账必须区分 `observed`、`synthetic`、`authored`、`reused_public`、`restricted`；观测数据必须记录覆盖范围，合成数据必须使用 `urn:synthetic:`，且不可写成实证。受限数据需记录合法访问条件，不自动下载、不发布敏感或付费数据。

模型门按研究类型适配：统计/经验研究检查训练—测试隔离、样本单位、分母、独立性、不确定性和多重比较；理论研究检查证明条件与反例；优化研究检查可行性、gap/收敛、基线、消融、敏感性和负结果。非适用项须写明理由，不能用空字段绕过。

每个重要数值 claim 应登记单位、分母、情景与结果来源；图表须绑定同一 run 的源工件。旧 run、失败、超时、stale hash 均阻塞。文献存在性、引文语义、全文写作范本分别登记，元数据不能替代全文或语义审查。
