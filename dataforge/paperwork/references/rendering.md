# 稿件渲染与版式验收

图件硬性要求：图内所有文字（坐标轴、刻度、图例、标注、面板标签）全英文，统一 Times New Roman，必须核验实际字体，缺字体时停止而非静默替换。按最终嵌入尺寸计算有效分辨率≥300dpi，期刊更严格要求优先。任何图例、文字、标记、曲线、轴题不得造成非数据含义的相互遮挡或裁切；预留独立图例区，最终尺寸逐图视觉检查，发现遮挡必须重新布局后再输出。数据曲线真实交点不属于排版遮挡；不得移动数据点伪造分离。中文正文图题可保留，除非期刊另要求英文。

## 唯一主稿与优先级

正文、数字、图表题注和文献引用只维护 draft/manuscript.md；转换器不能发明正文、作者、期刊规定或占位图题。优先级：官方模板 > 经核查的 journal-adaptation.md > 明示的工作稿默认值。模板没有落实到实际代码就视为未实现，不能仅在文档中写“按期刊要求”。

每项目记录实际采用的页面、标题、字体、题注、图宽、dpi、匿名及引用参数，逐项对应实现和验证位置。目标期刊没有规定的题名字号等只能标为工作稿选择，不冒充官方要求。复杂/未支持的官方模板或公式先报告阻塞，禁止静默降级。

## 执行

在包目录用 terminal 执行：

    python scripts/render.py latex <项目>
    python scripts/render.py docx <项目>

LaTeX 必须实际套用 templates/latex/manuscript.tex，输出含 documentclass、宏包、begin/end document 的完整源稿。模板占位为 @@TITLE@@ 与 @@BODY@@；生成稿不允许残留。编译在新目录执行，检查退出码、日志和本次输出；禁止因旧 PDF 仍存在而宣称成功。无 xelatex 明示“未编译”，保留源稿；通过可用 Word/WPS/LibreOffice 导出 PDF 时记录工具与版本，不声称 LaTeX 已验证可编译。

Word 依赖 python-docx；本包小型 SVG 转换器依赖 Pillow，不能使用忽略锚点/旋转/字形的位图字库当正式图件。缺依赖明确失败，按需使用 uv 隔离环境，不安装整套科学栈。

## 排版契约

1. 首个 # 是独立论文题名，位于首页顶部、居中，不编号、不当作 section。不得虚构作者/单位/日期；匿名要求优先。所有各级标题（题名、章标题、节标题）、摘要标题、关键词、表题、图题、图注均明确设置首行缩进为0；只有普通正文段落设置首行缩进约0.84cm。无官方模板时工作稿采用中文黑体22pt题名，宋体/Times New Roman 12pt正文、1.5倍行距、A4单栏、2.54cm边距；这些不是目标期刊强制的题名字号。
2. 摘要、关键词与正文章节层级清晰；引用块不得残留 >；正文不得出现原始 [@id]、Markdown ** 或模板占位。引用按 bibliography.json 映射为可读体例，缺项失败，元数据核验不等于阅读或语义支持。
3. 图居中、保持纵横比、不超过版芯。图题只出现一次且位于图下：可用图片 alt 作题注，或紧随图片的“**图 N：...**”；不得生成空“图”、重复“图 图 N”或占位题注。图与题注同页，来源/情景说明与图关联。
4. 表题在表上、三线表、不加竖线；单元格换行，不裁切、不超边距。宽表先缩短列名或合理分配列宽，不能靠极小字号掩盖溢出。
5. 每图有含单位的横纵轴、完整且不出界的图例；颜色使用 #0072B2 / #009E73 / #E69F00，并用不同线型或形状区分，禁止红色强调。按最终嵌入宽度检查字的实际可读性；矢量优先，栅格打印图工作稿至少300dpi（像素宽度/嵌入英寸），期刊更高要求优先。SVG保留；Word栅格图必须正确支持text-anchor、旋转、线型和字体，不能仅检查文件存在。
6. 编号按首次出现连续，对正文图表引用逐一核对；删图改号须同步正文、图注和图清单。公式为真实数学排版；不能把未经支持的LaTeX命令直接当Word公式通过验收。

## 必须双重验收

机械验收：测试通过；检查 DOCX OOXML 的题名对齐、字号、页面、三线表、图片宽度、图注数量及 keep-with-next；PDF文本逐项核对数字/引用/题注；缺图失败。核对每张图与results、run、figures.json。检查最终图像有效dpi，不以PNG元数据代替实际尺寸。

视觉验收：PDF全部页面渲染PNG（例如PDFium），逐页调用 vision_analyze，特别检查首页题名、每张图完整边界/图例/坐标、表格分页、图注同页和参考文献。另查看原始图的全尺寸预览。发现问题回到主稿/模板/转换器修复并重新生成，不直接修补PDF隐藏源稿问题。

写入 draft/render-review.json：主稿/模板/产物SHA、实际导出通道和版本、全部页数、每张图尺寸与有效dpi、逐页检查记录、问题及解决结果、未执行项目。机械通过不能代替视觉通过；LaTeX缺编译器须单列未验证，不能写“可编译已确认”。不要要求“PDF页数与Markdown一致”，Markdown无页数。

渲染与研究分开：validate只核查机械研究证据链；render-review另外验证版式，不代表科学评审、文献语义或真实投稿资格。重新生成前归档旧交付，勿覆盖其他Agent的版本。模型和计算口径不因排版变更而调整。
